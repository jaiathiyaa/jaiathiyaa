## ⭐ Featured Projects

### 🤖 Multi-Agent RAG Assistant

A production-oriented **multi-agent RAG system** built with LangGraph.

**Highlights:**

* Multi-agent state graph for intelligent query routing
* Routes requests across **RAG, web search, and LLM fallback**
* LLM-based router with deterministic rule-based fallback
* Critic agent with confidence-driven self-correction
* Bounded correction loop to prevent runaway agent execution
* HNSW-indexed retrieval using ChromaDB
* JWT authentication
* React 19 frontend
* Diagnostic trace UI for inspecting agent decisions

🔗 [View Repository](https://github.com/jaiathiyaa/Multi-Agent-Assistant)

### 🕵️ Karnataka Crime GPT

An AI-powered **conversational intelligence platform** for exploring and analyzing crime datasets.

**Highlights:**

* LangGraph-based multi-agent architecture
* Structured, semantic, graph, and hybrid retrieval
* PostgreSQL + pgvector
* Offender relationship/network visualization

### 🧠 Alzheimer's Disease Detection

A computer-vision system for **4-stage dementia classification from MRI scans**.

**Highlights:**

* Fine-tuned ResNet-18
* Custom Grad-CAM explainability module
* **98.30% test accuracy**
* **98.36% macro F1**
* Evaluated on a 6,600-image test set
* CPU inference benchmark: **86 ms mean latency**
* FastAPI inference API
* React-based visualization dashboard

🔗 [View Repository](https://github.com/jaiathiyaa/Alzheimer-Disease-Detection)
